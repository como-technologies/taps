# taps — suite-wide session rules

## Writing standard (STRONG REQUIREMENT)

All output follows ASD-STE100 (Simplified Technical English): short
sentences, active voice, one idea per sentence, plain words. Do not
coin jargon — if a term is not defined where the reader stands, do not
use it. This applies to everything we write: docs, book and guide
pages, kit files, CLI and report output, commit messages, and issue
comments. Existing text gets cleaned up under its own issue; new text
complies now.
