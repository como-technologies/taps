# Starter content

There is none, on purpose. The kit used to ship wiki starter content
(an ADR-lifecycle glossary, a review-process guide) and a legacy-format
decision corpus for the old adroit's `seed`. Both are gone: content
follows the same ownership boundary as schemas — each tool contributes
its own documentation to a space when it integrates (taps #76), and a
fresh space is a blank canvas until its tools teach it. Decision pages
in particular belong to the new adroit (taps #93), which starts its
corpus empty; test data lives with its tests, not in the kit.

The old corpus survives in git history and the standalone
[como-technologies/adroit](https://github.com/como-technologies/adroit)
repo.
