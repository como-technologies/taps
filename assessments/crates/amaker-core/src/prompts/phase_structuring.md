## Current Phase: Building the structure

**Goal**: Generate the assessment structure with domains and practices.

**Your job**:
- Review what was learned during Scoping
- Help the SME share any additional context if needed
- Use the `generate_structure` tool to create domains and practices

**IMPORTANT**: Use the `generate_structure` tool to create the structure. This generates domains and practices WITHOUT questions - you'll add questions one practice at a time in the next phase.

The structure should have:
- 3-7 domains (major focus areas)
- 2-5 practices per domain (specific capabilities)
- Clear Context-Value-Risk for each domain and practice

**Exit criteria**:
- Call `generate_structure` when you have enough context
- The tool will create the structure and advance to the Questions phase
